Мой стек живёт на агентах: Kiro, nekocli, opencode, OpenDesign, DSH.
Каждый говорит на своём диалекте одной и той же идеи — Anthropic-
совместимый messages API — и каждый хотел свой ключ, свой base URL и
свой конфиг-файл.

## Проблема — дрейф конфигов

Каждый новый агент = ещё один `.env`, ещё одно место, где утекает
токен, ещё один «а какой это URL был?». А когда модель переезжала —
я правил пять файлов.

## Одна точка

OmniRoute — Docker-сервис на `localhost:20128/v1`, который эмулирует
Kiro/Anthropic API и роутит настроенные бэкенды:

```
Kiro ───────┐
nekocli ────┤
opencode ───┼──► OmniRoute:20128 ──► модели
OpenDesign ─┤
DSH ────────┘
```

- Один URL, один секрет, пять потребителей.
- Алиасы моделей: `sonnet-4.5`, `sonnet-5`, `haiku` — централизованно.
- Бэкапы БД и скрипты обслуживания в комплекте.

## Локально-фёрст, всегда

Гейтвей работает у меня на машине. Ничего не идёт через чужой
аккаунт, телеметрия не покидает коробку, выдернутый кабель не ломает
пайплайн.

Дрейф конфигов: пять файлов → один. Весь питч на этом.
